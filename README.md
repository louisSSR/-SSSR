# 白 · 蝶翼商店 1.3.1

让聊天里已经成立的改变获得因果点，用点数兑换能力和物品；按剧情推荐委托，并保留印象、点数、消费与所得、连锁反应四类记忆。

本版保留“开始使用”首页、各页操作说明和可拖动的 48×48 Q版白入口；补全本轮多笔结算回执、剧情换世界后的商品列表，以及数据库界面中的实时四表。数据库木偶白主题以独立的酒馆助手脚本交付，商店、主题和四表分开更新。

## 安装和保留旧数据

Git 安装地址：[白 · 蝶翼商店仓库](https://github.com/louisSSR/-SSSR)。原仓库安装者检查更新后刷新页面，再核对扩展版本为 1.3.1。

先在旧版导出完整账本，再在酒馆扩展管理中更新商店并刷新页面。手动安装者，将本包文件覆盖到原商店扩展目录，保持目录和酒馆地址不变。不需要重建账户。

原有点数、交易和所得继续保存在原浏览器、原酒馆地址下。换手机、换浏览器或换酒馆地址前，导出完整账本，在目标端恢复。插件包不包含用户聊天、账本或 API 密钥。

## 从哪一步开始

1. 打开目标角色聊天。首次建立账本；已经用过则接续已有账户或恢复备份。“本源”就是跨世界保留数据的这份账本。
2. 在“兑换商店”填写想获得的能力或物品，例如“护送商队穿越雪原，需要耐寒与急救”，识别世界并按目标匹配商品。
3. 回聊天推进剧情，在“事件与点数”核对最新 AI 正文里已成立的改变。没有成立事实就不加点，不预支未来收益。
4. 看清商品完整效果、份数和总价，再确认兑换；结果保存在“已购所得”。
5. 在“剧情委托”描述想推进的人物或事件，接取建议后回聊天行动，目标实际成立后再核对。

“开始使用”首页按当前进度给出下一步入口。无聊天时，识别、生成委托、核对按钮停用并说明原因。

世界识别、推荐委托、核对事件会调用所选 API；接取委托、购买、手写印象和查看档案本身不调用模型。自动识别和回复后自动核对默认开启，创建账户前即可关闭，也可在“设置与备份”更改。接取委托只记录目标，不会自动发送聊天、完成任务或额外发点。

## 入口和手机界面

点 Q版白小圆钮打开商店，按住拖动改变位置。拖动结束不会误开商店；位置仅作为界面偏好保存，不影响账本。旋转或可见区域变化后，入口保持在屏幕内。

在酒馆扩展设置点“复位商店入口”可恢复默认位置。电脑也可聚焦入口后用方向键移动、Home 复位。手机顶部栏目保留文字并可横向滑动，商品和步骤卡片采用单列，金额保持完整数值。

## 数据库主题和四表

白／Q版白主题使用独立的酒馆助手脚本 JSON：到全局脚本库停用旧脚本，导入新版并确认新开关已开启，若关闭再打开。若装过旧白主题扩展，请先在扩展管理中停用。关闭脚本恢复原数据库外观，不改源码和表数据；原数据库按自身方式更新。

商店内四表随账本更新，完整历史留在本地，每轮按预算提供摘要。与新版独立主题一起启用时，数据库界面内的“蝴蝶四表”显示同一本源的实时记录；任务、印象、点数与所得提交后刷新，分页查看不会删历史。

另可在“记忆四表”导出包含全部业务记录的原生四表 JSON。原数据库 1.2.5 的“导入模板 JSON”用于建表，会将文件中的数据行作为初始化数据；它不能直接恢复完整运行记录。日常查看使用实时四表，换设备使用完整账本备份。完整原生快照的数据导入方法及覆盖范围见 [四表说明](docs/four-tables-install.md)。

已有其他表格时先备份，再使用原数据库的合并流程保留旧表，导入不保证自动合并。手改数据库余额不修改商店账本。空白四表模板只建立结构，不会自己派发任务或获得点数。详见 [四表导入说明](docs/four-tables-install.md)。

四表默认关闭重复世界书注入和自动填表，不要手动将这些快照表再次发送给 AI。默认 2048 Token 预算只约束本插件摘要，不代替其他世界书和角色卡的上下文设置。

## 规则和维护

点数来自已成立事实，已有收益不追扣；固定报价和完整规格沿用旧规则。模型语义判断并非绝对准确，事件证据和交易回执可在“事件与点数”核对。所得跨世界保留，消耗和移交按实际发生登记。

`src/` 为源码，`index.js` 为已构建入口，`assets/` 为主题图，`database/` 为模板和配色。普通用户无需编译。维护者使用 Node.js 24 或更新版，安装声明依赖后执行 `npm run typecheck`、`npm test`、`npm run build`。

针对 SillyTavern 1.18.0、数据库 1.2.5、酒馆助手 4.8.18 验证；其它版本及实体手机系统键盘不视作已测。当前范围见 [1.3.1 要求核对与验证](docs/acceptance-v1.3.1.md)，前版证据留在 [1.3.0 修复说明](docs/acceptance-v1.3.0.md)。旧版说明留在 `docs/README-v1.2.0.md`。
