# 白 · 蝶翼商店 2.0.0

插件直接管理原数据库的四张蝴蝶表：重要印象、点数账目、消费与所得、连锁反应与任务。原生四表是业务数据来源，完整历史随当前聊天保存。主题脚本、商店插件、四表空模板分别安装和更新。

## 安装与开始

index.js 已构建，普通用户无需编译。手动安装覆盖原商店目录并保留 .git，避免同时安装两份。Git 来源是 [LouisSSR 的商店仓库](https://github.com/louisSSR/-SSSR)，更新后核对实际版本为 2.0.0；旧 1.3.x 没有本版四表业务管理。

数据库必须使用 SQLite 模式。官方 1.2.5：连续点击左上数据库名称 5 次开启进阶模式，在仪表盘 → 高级设置中选择 SQL；按原生提示保存并重新载入。默认 native 模式无法提交本版事务，插件会在写前暂停并给出提示，不自动修改数据库设置。

1. 备份原数据库和旧商店完整账本，启用原数据库并打开目标聊天。
2. 下载 database/butterfly-memory-four-tables.json 空模板。在原数据库模板页面安装四张表，保留其它表。保存后关闭编辑器。
3. 返回商店刷新。首次初始化从 0 点开始；恢复则选择完整账本备份，目标四表必须为空。
4. 识别当前世界和商品，回聊天推进故事，再核对已成立因果。看清效果、份数和总价后确认兑换。
5. 派发和接取剧情委托，实际结果成立后统一结算。接取不会额外发点，消耗与移交按真实发生登记。

每段聊天各有一份本源，不自动搬入其他聊天的钱包；同一聊天内换世界保留历史、报价和所得。原生已有数据优先读取。旧版 IndexedDB 仅在你点“查找旧备份”时只读导出；可显式恢复到指定聊天的空四表，不合并或覆盖原生历史。

## 四表与保存

| 原生表 | 完整内容 |
| --- | --- |
| 重要印象 | 人物、承诺、已确认事实与依据，变化追加记录 |
| 点数账目 | 本源身份、全部交易、计功事件和固定标准；余额由交易推导 |
| 消费与所得 | 完整固定报价、未买商品、所得、使用和移交数量 |
| 连锁反应与任务 | 当前和历史余波、派发、接取、搁置及完成依据 |

可读业务列是数据来源，嵌套结构保存在对应 JSON 列。插件不另存隐藏账本或四表副本。获得同源跨标签锁后先核对服务器上的当前聊天，再提交原生 SQL 批次；批次检查旧记录和约束。写后回读原生表和目标聊天，确认保存才显示成功。

未保存、旧标签缓存或身份变化会暂停写入。回到原聊天刷新核验或重新载入，勿重复兑换。不提供自由改余额。原生编辑器打开时暂停商店业务写入。完整备份只能恢复到空四表。

## AI 预算与规则

默认每轮新增记忆预算 2048 Token，可选 4096 / 8192。分词器失败或超时使用保守 UTF-8 字节上限。省略记录不会删历史、取消所得或重新定价。预算只约束本插件新增记忆，不替代角色卡、聊天和其他世界书设置。

四表默认关闭世界书注入与自动填表，避免重复发送或模型改账。世界识别、因果核对与委托推荐调用你已配置的酒馆 API 或数据库预设；插件不另存密钥。自动功能可关闭。语义判断需要核对证据，模型叙述不等于购买成功。

## 手机、主题与更新

48px Q 版白入口可拖动，闲置 5 秒吸附左右边半隐，屏内触摸区域至少 44px，点击直接打开。扩展设置可复位。旋转后重新限位，键盘弹出时暂时收起装饰，收键盘后恢复位置。

白主题 1.3.0 是独立酒馆助手脚本：先停用旧白主题，导入 theme-script/dist/shiro-database-theme.script.json 并确认新版开启。收起时用独立正向头部与双手，展开保留完整六态木偶身像。保留原生查看、编辑和保存，不再创建四表副本；停用恢复外观。原数据库继续自行更新。

安装与恢复详见 [四表说明](docs/four-tables-install.md)。源代码核验基线为 SillyTavern 1.18.0 与官方数据库 1.2.5。实际运行与未测边界见 [本次验收记录](docs/acceptance-v2.0.0.md)；实体手机系统键盘、跨设备同时写同一聊天、用户对造型的验收独立记录，上游变化需重新适配。
