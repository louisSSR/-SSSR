# 木偶白 1.2.1：靠边裁切修复

手机上把木偶拖到右边，原生缩边状态会将 64×64 的人物旋转 −90°，却仍用约 36×64 的半身探头窗口裁切；左边同理。此前只核对了图片尺寸、旋转和一般手机布局，遗漏了完整人物在窄裁框里的实际可见区域。

本版仅调整拥有白素材的探头窗口：沿完整图片展开为正方形，向屏幕内部放置，并为原生向外的 4px 探头动画留出余量。原生根节点和图片的 inline 尺寸、定位、图片来源及拖动处理器保留；扩出的区域仍能接收原生点击和拖动。停用主题恢复原生半身窗口。商店仍为 1.3.1，四表和图片素材没有改动。

最终主题 JSON SHA256：`2cf2a7135ec56049246a9b0537a982cb207bfb29ae5dc91e434e7c757f2288eb`。

验证结果：

- 37 项自动检查、严格 TypeScript、正式构建及输出格式校验通过。
