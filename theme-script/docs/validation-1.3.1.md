## 源码事实与修正

对照的官方 `DeskPet.vue` 中，未存停靠位置时 `dockEdge=null`，原生默认位置距右边 16px；存在已存 `edge` 时才恢复停靠，并在 4 秒后收拢。`showPeek` 同时要求停靠边、已收拢、未拖动和无反应。因此，不能把未存设置的初始位置说成“原生默认停靠”。

1.3.0 只根据 body／peek 容器存在与否选资源，对探头节点没有验证 `is-tucked`、真实四边接触或拖动状态；原有回归也直接构造探头节点，没有真实状态和几何。1.3.1 仅在原生已收拢、未拖动、明确单一边且当前根边界与相应视口边相差不超过 2px 时选独立头手；其他已识别节点保持六态完整木偶。

正常 drag 坐标由原生拥有。主题旁听其 style／class、指针和停靠 transitionend；窗口变化重新计算几何。不监听 hover 来选择资源，不主动修改原生位置或保存边，不添加轮询。暂留探头容器中的完整木偶也使用 300%×200% 单格背景和 4px 运动空间，不把整张六格图缩成一幅。
