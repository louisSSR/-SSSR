# 白 · 空白棋局数据库主题：木偶白脚本版 1.2.1

只需导入一个 **`dist/shiro-database-theme.script.json`**。数据库现在使用专属木偶白，页眉、侧栏和原生桌宠均改用独立六态素材；图片与主题样式已完整内嵌。

1. 在酒馆助手的**全局脚本库**先停用此前的白主题脚本（包括 1.2.0），再导入这个 JSON。新版名称含“木偶白 1.2.1”；导入器可能创建新脚本，不能假定稳定 ID 会自动覆盖旧版，请避免旧新两份同时启用。
2. 导入后确认名称含“木偶白 1.2.1”的新脚本开关已启用；若开关关闭，再手动打开“白 · 空白棋局数据库主题 · 木偶白 1.2.1（酒馆助手脚本）”。
3. 打开原数据库，即可看到白主题。手机和电脑使用同一文件。

停用脚本会恢复原数据库外观。脚本按钮“切换白主题”可以暂时切换外观，“主题状态”显示当前情况。按钮开关只影响本次运行；重新加载已启用的脚本后默认开启。

1.2.1 修复木偶靠边横过来时只露一截的问题。原生探头会把 64 像素图片裁进约 36 像素宽的窗口；现在白的窗口保持完整方形，向屏幕内展开，并为四边的探头动画预留 4 像素。展开的部分仍能点击、拖动，停用主题恢复原生裁框；商店和四表无需重新安装。验证范围见[1.2.1 裁切修复](docs/validation-1.2.1.md)。

数据库侧栏提供 **“和白开个玩笑”**，也可以点木偶头像。白会轮流说一句本地短吐槽，4 秒后淡出；连续点击有 3 秒冷却。“安静一会儿”停止本地玩笑、眨眼及已识别桌宠父层的 CSS 呼吸／探头动画；“让白说话”恢复，均只影响本次脚本运行。安静不冻结原生 JavaScript，宿主仍能切换姿态或位置，用户仍能拖动。桌宠被戳、拖起、放下和缩到屏边时有不同表情；原生拖动、缩边和真实通知功能继续保留。系统开启减少动态效果时，木偶装饰动画停止。

如果装过旧“白 · 空白棋局数据库主题”扩展，请先在**扩展管理中停用该扩展**，再启用此脚本。只关闭旧扩展内的配色开关不等于停用扩展。商店 1.1.1 及更旧版本包含内置主题，请先升级到 1.2.0；脚本发现这些旧主题仍在运行时会提示并等待，不替你关闭其它扩展。

主题、蝴蝶商店、原生四表 JSON 继续分开交付。本脚本不要求安装商店，不向原生数据库创建或写入表格。搭配商店 **1.3.1** 后，数据库侧栏的 **“蝴蝶四表”** 打开数据库内实时面板；内容区也有展开／收起入口。“白的委托”打开商店委托页。商店停用后这些入口与订阅一起移除。

实时四表直接读取当前本源已提交的完整业务记录：印象、精确点数账目、消费与所得、当前／历史余波与任务。四类分别查看，每表每页 50 条，搜索会查找完整四表；购买、消费与委托提交后自动重读，版本和当前本源显示在面板中。切换聊天、本源或登录状态会先清空旧资料，迟到读取不能带回前一个本源。原生表导入文件是独立快照，原生编辑不会反写商店；“导出完整四表”可下载当前完整原生 JSON，恢复时须先注册模板、适配实际表身份，见[四表说明](https://github.com/louisSSR/-SSSR/blob/main/docs/four-tables-install.md)。此只读视图与导出不注入 AI，不受本轮摘要预算裁剪，也不代替账本备份。

本脚本覆盖当前数据库的可见样式和装饰节点，不修改数据库源码、配置或原生行数据，数据库仍可正常更新。可选四表只读商店公开分页服务，不读取原生私有数据仓库。图片不从外部服务加载；脚本不调用模型，不改 Token 预算，不写聊天、账本或变量。后续数据库若改变界面结构，脚本会停止装饰并保留原生界面。

手机调整：缩小顶部装饰，填表状态改为完整的分栏卡片，说明按钮和长输入不再挤出屏幕；编辑器保留三个原生保存入口。打开数据库时收起普通 info／success 提示，可从侧栏“显示数据库提示”重新查看；警告、错误和带操作按钮的提示始终保留。单条可见提示安置在顶部通知区，并为数据库、编辑器、抽屉和对话框留出实际空间；内容过长可在原气泡内滚动。多条可见通知保留原生几何，基础手机视口样式独立保留。界面会跟随可见视口缩小及移动，关闭数据库或主题后恢复原生通知位置；停用主题会移除自己的尺寸样式与监听。

1.2.0 新增实际四表视图，补上安静状态的原生父层动画暂停与导出失败反馈。37 项自动检查、严格 TypeScript 与正式构建通过，覆盖只读服务、搜索分页、消费／任务提交刷新、跨本源迟到读取、订阅清理、双加载顺序、导出拒绝处理和原生节点保留；最终固定文件组合的 10 项隔离宿主检查通过，包含实时四表、主题启停、三种触控尺寸原生保存与服务器读回，详见[验证范围](docs/validation-1.2.0.md)。前版手机、素材与互动证据保留原版本身份，不计作本版全部重跑。其它完整正文、error 及带操作按钮的真实通知没有主动生成，实体 iOS／Android 键盘尚未测试；造型是否合意仍由用户目测确认。

源码维护：本目录自包含；`npm install` 后可执行 `npm run typecheck`、`npm run build`、`npm test`。正式使用只需导入 JSON。`script-spec.json` 保留稳定脚本身份；`build.cjs` 将代码、CSS 和 1536×1024 的透明木偶 PNG 打入单文件。PNG 为 3 列 2 行，每格 512×512，顺序 idle／blink／smug／poke／carried／peek；界面通过 `background-size:300% 200%` 只显示一格。
