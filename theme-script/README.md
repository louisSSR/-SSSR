# 白 · 空白棋局数据库主题：酒馆助手脚本版 1.0.1

只需导入一个 **`dist/shiro-database-theme.script.json`**，不用 Git，不用安装白主题扩展。白／Q版白图片和主题样式已全部内嵌。

1. 在酒馆助手中打开**全局脚本库**，导入这个 JSON。
2. 酒馆助手导入时会默认关闭脚本；手动打开“白 · 空白棋局数据库主题（酒馆助手脚本）”的开关。
3. 打开原数据库，即可看到白主题。手机和电脑使用同一文件。

停用脚本会恢复原数据库外观。脚本按钮“切换白主题”可以暂时切换外观，“主题状态”显示当前情况。按钮开关只影响本次运行；重新加载已启用的脚本后默认开启。

如果装过旧“白 · 空白棋局数据库主题”扩展，请先在**扩展管理中停用该扩展**，再启用此脚本。只关闭旧扩展内的配色开关不等于停用扩展。商店 1.1.1 及更旧版本包含内置主题，请先升级到 1.2.0；脚本发现这些旧主题仍在运行时会提示并等待，不替你关闭其它扩展。

蝴蝶商店和四表继续分开使用：本脚本不要求安装商店，不创建表格。启用商店 1.2.0 后，数据库侧栏会出现“四表”“委托”快捷入口；商店停用后入口消失。

本脚本覆盖当前数据库的可见样式和装饰节点，不修改数据库源码、配置或行数据，数据库仍可正常更新。图片不从外部服务加载；脚本不调用模型，不改 Token 预算，不写聊天、账本或变量。后续数据库若改变界面结构，脚本会停止装饰并保留原生界面。

手机调整：缩小顶部装饰，填表状态改为完整的分栏卡片，说明按钮和长输入不再挤出屏幕；编辑器保留三个原生保存入口。打开数据库时收起普通轮播提示，可从侧栏“显示数据库提示”重新查看；警告、错误和带操作按钮的提示继续保留。界面会跟随可见视口缩小及移动，关闭主题后移除自己的尺寸样式与监听。

已验证版本：SillyTavern 1.18.0、酒馆助手 4.8.18、龙血玄黄·数据库 1.2.5。1.0.1 完成 21 项自动检查与独立隔离宿主验证：320／390／844 像素下的仪表盘、填表、API、数据管理、高级工具与编辑保存；长表单、取消确认弹窗、提示入口、停用恢复，以及原生 Q版白桌宠触控拖动和缩边。针对最后的普通提示遮挡修正，单独复验可见性分支、三档页面截图与商店共同启用时的保存避让。键盘场景通过控制 visualViewport 的 resize／scroll 信号模拟，移动操作使用桌面 Chromium 触控模拟，尚未在实体 iOS／Android 键盘上测试；其它插件版本不视作已验证。主题自身无需远程图片或代码，酒馆助手自身的启动和更新行为不属于本脚本。

源码维护：本目录自包含；`npm install` 后可执行 `npm run typecheck`、`npm run build`、`npm test`。正式使用只需导入 JSON，不需要构建工具和中间文件。`script-spec.json` 固定脚本身份与按钮；`build.cjs` 将代码、CSS 和 PNG 打入单个导入文件。
