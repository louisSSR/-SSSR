# 白 · 空白棋局数据库主题：木偶白脚本版 1.1.0

只需导入一个 **`dist/shiro-database-theme.script.json`**。数据库现在使用专属木偶白，页眉、侧栏和原生桌宠均改用独立六态素材；图片与主题样式已完整内嵌。

1. 在酒馆助手的**全局脚本库**先停用旧 1.0.x 白主题脚本，再导入这个 JSON。新版名称含“木偶白”；导入器可能创建新脚本，不能假定稳定 ID 会自动覆盖旧版，请避免旧新两份同时启用。
2. 导入后确认名称含“木偶白”的新脚本开关已启用；若开关关闭，再手动打开“白 · 空白棋局数据库主题 · 木偶白（酒馆助手脚本）”。
3. 打开原数据库，即可看到白主题。手机和电脑使用同一文件。

停用脚本会恢复原数据库外观。脚本按钮“切换白主题”可以暂时切换外观，“主题状态”显示当前情况。按钮开关只影响本次运行；重新加载已启用的脚本后默认开启。

数据库侧栏提供 **“和白开个玩笑”**，也可以点木偶头像。白会轮流说一句本地短吐槽，4 秒后淡出；连续点击有 3 秒冷却。“安静一会儿”停止玩笑与木偶眨眼，“让白说话”恢复，均只影响本次脚本运行。桌宠被戳、拖起、放下和缩到屏边时有不同表情；原生拖动、缩边和真实通知功能继续保留。系统开启减少动态效果时，木偶装饰动画停止。

如果装过旧“白 · 空白棋局数据库主题”扩展，请先在**扩展管理中停用该扩展**，再启用此脚本。只关闭旧扩展内的配色开关不等于停用扩展。商店 1.1.1 及更旧版本包含内置主题，请先升级到 1.2.0；脚本发现这些旧主题仍在运行时会提示并等待，不替你关闭其它扩展。

蝴蝶商店和四表继续分开使用：本脚本不要求安装商店，不创建表格。启用商店 1.2.0 后，数据库侧栏会出现“四表”“委托”快捷入口；商店停用后入口消失。

本脚本覆盖当前数据库的可见样式和装饰节点，不修改数据库源码、配置或行数据，数据库仍可正常更新。图片不从外部服务加载；脚本不调用模型，不改 Token 预算，不写聊天、账本或变量。后续数据库若改变界面结构，脚本会停止装饰并保留原生界面。

手机调整：缩小顶部装饰，填表状态改为完整的分栏卡片，说明按钮和长输入不再挤出屏幕；编辑器保留三个原生保存入口。打开数据库时收起普通 info／success 提示，可从侧栏“显示数据库提示”重新查看；警告、错误和带操作按钮的提示始终保留。单条可见提示安置在顶部通知区，并为数据库、编辑器、抽屉和对话框留出实际空间；内容过长可在原气泡内滚动。多条可见通知保留原生几何，基础手机视口样式独立保留。界面会跟随可见视口缩小及移动，关闭数据库或主题后恢复原生通知位置；停用主题会移除自己的尺寸样式与监听。

1.1.0 当前成品通过 27 项自动检查、严格 TypeScript 与正式构建，并在 SillyTavern 1.18.0、酒馆助手 4.8.18、龙血玄黄·数据库 1.2.5 中完成 12 项手机通知避让的真实宿主定向验证：原生 warning 外观的占位气泡保留可见、原生关闭／下一条可点，320 像素页面的输入和三个保存入口避开通知，实际保存成功。六态素材、眨眼、玩笑与减少动态效果沿用同图集前一候选的 11 项真实检查；触控拖动、四向缩边和原生重复导入等行为明确继承更早候选的 5 项证据，未计作当前文件全部重跑。详见[验证范围](docs/validation-1.1.0.md)。其它完整正文、error 及带操作按钮的真实通知没有在本轮主动生成，实体 iOS／Android 键盘尚未测试；造型是否合意仍由用户目测确认。

源码维护：本目录自包含；`npm install` 后可执行 `npm run typecheck`、`npm run build`、`npm test`。正式使用只需导入 JSON。`script-spec.json` 保留稳定脚本身份；`build.cjs` 将代码、CSS 和 1536×1024 的透明木偶 PNG 打入单文件。PNG 为 3 列 2 行，每格 512×512，顺序 idle／blink／smug／poke／carried／peek；界面通过 `background-size:300% 200%` 只显示一格。
