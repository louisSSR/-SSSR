# 白 · 空白棋局数据库主题：木偶白脚本版 1.3.1

本组件给原生数据库添加白主题与轻量木偶装饰。交付文件是 `dist/shiro-database-theme.script.json`，代码、样式、六态完整身像与独立透明探头均内嵌在一个酒馆助手脚本 JSON 中。

1. 在酒馆助手的**全局脚本库**停用此前所有白主题脚本，再导入新版 JSON。导入器可能创建新 ID，不能假定自动覆盖旧版。
2. 确认名称含“木偶白 1.3.1”的脚本已启用，并仅启用这一份主题。
3. 打开原数据库。手机和电脑使用同一文件；停用脚本恢复原生外观。

“切换白主题”暂时切换外观，“主题状态”显示当前状态。开关与安静状态只影响本次运行，不写宿主设置。旧独立主题扩展或旧商店内置主题还在运行时，本脚本提示并等待；请在扩展管理中停用旧主题，避免旧版本重新接管。

## 原生四表与任务入口

1.3.0 已移除主题自建的四表副本、抽屉、搜索分页和账本订阅。查看、编辑、保存和更新使用原生四表与原控件；主题只修饰原生 UI，不创建、复制或改写表格，也不执行数据迁移。旧 snapshot 服务不会被主题消费。

主题可以独立使用。搭配蝴蝶商店 2.0.0 时，侧栏“白的委托”打开商店委托页；商店停用后入口移除。商店的 **48px 可拖动浮球**、闲置 5 秒吸边半隐和位置保存属于商店插件，不属于这个主题脚本。

## 木偶白

平时、初始化和离墙都使用 `assets/shiro-puppet-sheet.png` 的六个完整木偶身像，无需鼠标碰触。只有原生已收拢、未拖动且人物实际贴住相应视口边，才切换 `assets/shiro-peek-head-hands.png` 的正向头部与双手。拖离墙、取消收拢或视口变宽使人物离墙时，立即恢复完整木偶；即使 Vue 暂时保留旧探头节点，也显示六态单帧。原生停靠过渡完成时重新核对实际接触，没有 hover 依赖或轮询。已保存四边停靠的位置可继续使用探头；未保存停靠时，原生默认位置显示完整木偶。

探头四边均直立，不将完整人物横转当探头。主题只读取原生尺寸和几何，保留原生拖动坐标，并留 4px 运动余量；停用恢复原生图片与裁框。素材为内置图像生成工具制作的同人图，生成来源和提示词见[素材记录](docs/puppet-art.md)。

侧栏“和白开个玩笑”或木偶头像触发本地短吐槽，3 秒冷却、4 秒淡出。“安静一会儿”暂停本地玩笑、眨眼和已识别父层 CSS 动画；“让白说话”恢复。安静不冻结原生 JavaScript，用户仍能拖动。玩笑不调用模型、不读取表格行、不写聊天、账本或变量；系统开启减少动态效果时装饰运动停止。

## 手机布局与键盘

原生数据库窗口、编辑器、抽屉和对话框跟随可见视口与安全区，长内容在面板内部滚动。输入聚焦时隐藏木偶与额外装饰，失焦恢复；旋转和视口变化取消旧手势。原生保存与关闭控件保留。

普通 info/success 提示可从侧栏“显示数据库提示”查看。警告、错误和带操作按钮的真实通知保留；单条可见通知放入预留的顶部空间，长通知内部滚动。多条通知保留原生几何。停用主题清理自有样式、装饰和监听；未知数据库结构停止装饰并保留原生 UI。
