## 边界

- 官方数据库没有安全聊天绑定写回接口；自动原生六表同步仍仅适用于旧固定兼容桥。独立四表/任务在本插件中自动更新；原生四表导入是快照，需要重新导出导入刷新。
- 完整历史永久保留于浏览器本源账本及用户备份。有限上下文无法同时发送无限细节；摘要按优先/相关性选择，界面明确显示省略数量并提供检索。
- 默认2048/可选4096/8192只限本插件记忆；评估请求文本上限8000。宿主分词器部分配置可能估算；失败采用字节保守预算。未保证所有角色卡、聊天、世界书及其他扩展的总Token。
- 新版未知DOM不强行装饰；实际最新版remote HEAD查询超时，只报告已核验的1.2.5。
- 真实群聊、外部付费模型、用户现用数据与人工验收未完成。本次开发与隔离验证不等于用户已经接受或安装。
