# 白 · 蝶翼商店

一个原生 SillyTavern 商店扩展，以及配套的蝴蝶效应数据库六表和白主题。规则来自你提供的《蝴蝶效应.txt》，原文保存在 `docs/蝴蝶效应原文.txt`。

## 安装与使用

1. 关闭酒馆页面，把包内 `shiro-butterfly-shop` 文件夹放入当前酒馆登录用户的 `SillyTavern/data/<用户>/extensions/`。例如单用户默认目录是 `data/default-user/extensions/shiro-butterfly-shop`。文件夹内应直接看见 `manifest.json`、`index.js`、`assets` 和 `database`。
2. 如果要自动同步数据库表格，在备份现有 shujuku 扩展文件后，用整合包里的 `shujuku-1.2.5-shiro.1` 文件替换该数据库扩展目录中对应的文件。保留原目录名和原用户数据。此兼容版固定基于上游 1.2.5；它增加按聊天身份绑定的保存接口。其他版本可先使用原生六表导入和主题文件。
3. 刷新酒馆，在扩展管理中确认“白 · 蝶翼商店”启用。点击右下角的 Q 版白，或扩展设置中的同名按钮打开。
4. 打开一个聊天，连接酒馆中你已有的 API。在商店建立一份“本源”账户，初始余额为 0。默认进入聊天会识别世界并生成商品，故事回复后会核对已成立的因果；可在“本源与连接”中关闭自动调用。
5. 商品“查看规格”会展示完整八项规格。确认份数和总价后兑换，点数、所得、交易回执一并保存。稀有商品从初始即可查看，余额不足会显示差额。
6. 在“蝴蝶表格”点击“接入当前聊天”。兼容数据库会添加六张表并保留其他现有表；之后交易自动同步。原版数据库可使用“导出当前六表”得到包含真实账目的原生文件。
7. 打开数据库本体右上角“外观 → 导入主题”，选择 `database/shiro-v2-theme.json`。旧版数据库界面使用 `shiro-legacy-theme.json`，两种格式不要混用。

## 包含的成品

| 文件 | 用途 |
| --- | --- |
| `manifest.json`、`index.js` | 已构建的原生商店扩展，无需自行编译 |

六张表分别记录因果总览、因果与余波、恒量计功参照、永久商品报价、交易回执、长期所得。表格是商店账本的投影，不能通过修改表格凭空加点。

## 跨世界与本源

同一酒馆登录用户可以建立多个互相独立的本源。选定的本源跨角色、聊天、世界和 Persona 延续；死亡、转生不会自动建立新账户或重置点数。不同酒馆登录用户互相隔离。

永久账本保存于浏览器 IndexedDB，并使用单次事务提交点数与所得，两个标签页不会各自花掉同一份余额。换浏览器、清理网站数据或更换酒馆地址之前，务必在“本源与连接”导出完整账本。也可备份到酒馆服务器，程序会在写入后读回核验。恢复备份会建立新本源，避免覆盖原有有效历史。

## API 与计功规则

默认使用酒馆当前 `generateQuietPrompt()` 连接，包含聊天和按酒馆规则激活的世界书；也可选龙血玄黄数据库的已配置 API 预设。数据库预设路径显式携带角色资料、最近 12 条故事和绑定世界书。额外资料可填写在世界补充栏，不会直接成为收益证据。商店不要求另填密钥，也不导出密钥。

只有实际成立的新结果才能计功，API 必须引用本轮已完成故事中的原句。未来余波只追踪，不预支。重复结果 ID 和完全相同事实会去重，已确定计功标准和效果报价不可改写。加深与新相关事件需要独立新增结果，并指向原事件。模型无法凭返回字段发起购买或扣款。

原文没有给出数值奖励公式或统一商品价格表。新标准和新报价由所选模型根据原文评估，固定保存；同义事实与同义效果的语义判断仍取决于模型，账本会保留来源与证据供核对。程序对规范化后完全相同的事实和规格进行严格去重与锁价。数值实现支持最多 48 位整数、18 位小数，使用精确运算。

1 点标准生命本源增益常驻。N 份永久叠加 N 份同样的肉体、灵魂和承载底蕴，保留种族、人格、记忆与自我连续性。每项商品绑定所得、强度、数量、范围、持续时间、次数、承接条件、跨界效力八项规格；永久所得持续保留，消耗资源与物品移交在“我的所得”按实际发生登记。

每笔交易输出原文要求的 `<WJWK-settle>` 回执。既有所得及最近回执会注入后续故事，支持模型承认完整到账与跨界效果；停用插件会清除本插件的注入、界面和事件监听，账本仍保留。

## 版本与验证

固定宿主：SillyTavern 1.18.0，核心提交 `8172dcd0ee672d3cd9a5e5f7af134f91a45cd2b8`。
固定数据库：AlbusKen/shujuku 1.2.5，提交 `1a5ffdb3ef8817452c370c6cfef7cac86683d7cc`。来源：<https://github.com/AlbusKen/shujuku>。

自动检查、真实隔离宿主证据和未测试范围见交付包的验收记录。测试使用独立的酒馆资料、合成魔法/科技世界和无密钥本地 API。模型协议通过不代表任意外部服务都会返回合格 JSON。用户实际连接和角色的生成效果由用户使用时确认。

本包没有自动安装到你正在使用的酒馆，也没有改动现有角色、聊天或凭据。

## 从源码构建

在具有 Vue 3、webpack 5、vue-loader 17、ts-loader 9 和 TypeScript 的项目中执行 `node extensions/shiro-butterfly-shop/build.cjs`；相对路径按源码放置位置调整。执行 `node --test extensions/shiro-butterfly-shop/tests/core.test.mjs extensions/shiro-butterfly-shop/tests/integration.test.mjs` 验证核心与联动。真实浏览器测试脚本仅面向已准备好的独立测试宿主，不能对生产聊天直接运行。
