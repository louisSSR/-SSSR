## 明确边界

- 没有安装到用户现有酒馆；按随包说明安装即可。用户人工体验尚未作为自动验收结论。
- 外部付费模型未调用。实际生成内容、估价和因果语义判断依赖用户选择的模型；程序验证结构、引用证据、精确金额、已定标准、事实及请求去重。
- 规范化后完全相同的事实和效果不会换 ID 重复入账或变价。自由文本的完全同义改写无法由字符串算法普遍判定，API 会携带完整旧记录要求复用，账本保留证据供核对。
- 真实群聊 UI 与旧版主题界面未执行端到端验收；群聊保存协议已做源码核对和确定性测试，旧版主题按其原生格式提供。当前 V2 主题与单角色跨世界流程已实测。
- 酒馆聊天文件接口没有服务器 CAS；其他扩展、标签或设备同时直接保存同一聊天时，仍遵循宿主的并发边界。商店余额由自己的 IndexedDB 原子账本负责，数据库投影失败可以重试，不撤销有效购买。

本轮发现的问题已修正并保留失败与通过证据，包括原生 IDB 错误时序、同事实换 ID、手机固定浮层、数据库聊天身份及持久化确认问题。三条复盘已按项目规则追加到防复犯记忆；历史记忆库另有旧路径/旧行哈希缺口，与本交付无关，未改写旧记录。
