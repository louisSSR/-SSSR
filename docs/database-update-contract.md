# 数据库、主题与商店分别更新

| 交付 | 安装 | 职责 |
| --- | --- | --- |
| 白主题 1.3.1 | 全局脚本库 JSON，先停用旧版 | 原生外观、木偶和手机布局 |
| 蝶翼商店 2.0.0 | Git 或已构建目录 | 管理原生四表、购物、任务与预算记忆 |
| 四表 v2 空模板 | 原数据库模板页面，保留其它表 | 当前聊天业务结构 |

官方数据库仍自行更新，本交付不默认替换它或安装旧兼容分叉。源核验基线为 SillyTavern 1.18.0、官方数据库 1.2.5，上游 API 或布局改变需适配。

升级先备份旧完整账本和原数据库。商店读取原生四表；旧 IndexedDB 只提供显式只读导出，恢复只允许指定聊天的空四表，不自动合并。每聊天唯一账户，原生历史优先。

主题不再创建四表副本。完整档案用原生数据库查看；商店记忆页是本轮 AI 摘要。停用商店清理自己的注入，停用主题恢复外观，两者分别更新。

旧六表、旧快照和 1.2.x 四表视图保留历史身份，不能作为当前业务来源。旧桥和全表覆盖不是默认安装步骤。详情见 [四表说明](four-tables-install.md)。
