# 1.3.0 修复范围与验证

本版针对用户反馈的三点：使用内容和下一步不明确、入口过大且无法移动、数据库主题在手机上排版不完整。

- 新增“开始使用”首页，显示世界、当前账本、点数和下一步。各页明确输入、操作、结果及是否调用 API；无聊天时解释并禁用识别、生成委托与核对。接取委托后可返回聊天推进，关联结果显示实际描述。
- 商店入口缩为 48×48，支持鼠标、触摸拖动，拖动不误开，保存位置并适应屏幕尺寸变化；扩展设置提供复位，键盘方向键也能移动。
- 独立主题脚本 1.0.1 收紧手机页头，重排工作台五项状态和面板按钮，处理普通通知遮挡、宿主变换后的页面偏移、可见视口缩小与弹窗保存区域。

商店账本、点数计算、交易、任务规则、四表结构未迁移。账户继续保留；controller 仅改默认打开的栏目。原数据库程序不覆盖、不替换。

静态检查：商店 63 项自动检查、类型检查、构建和扩展清单检查通过；主题 21 项自动检查、类型检查、构建和组件格式校验通过。独立审查检查了首用流程与实际能力的对应、入口清理和主题生命周期。

实际运行验证采用隔离 SillyTavern 1.18.0、数据库 1.2.5、酒馆助手 4.8.18，数据为合成测试资料。三种尺寸为 320×640、390×844、844×390，覆盖仪表盘、填表工作台、API、数据管理、高级工具，以及编辑器保存。商店另验证首用说明、旧账本与入口交互。

可见视口缩小、偏移和键盘空间通过桌面 Chromium 中的信号模拟验证，**不是实体 iPhone／Android 系统键盘测试**。不同上游版本不视作已通过。测试没有使用收费模型，也没有安装或修改用户日常酒馆实例。

主题页面和保存矩阵先完成基线验证；最后只调整普通提示的可见性，针对该差异重新验证三档截图、提示分支、联合保存和停用恢复。商店使用独立浏览器上下文验证，旧账本和世界状态采用明确标记的合成资料。

交付目录只在独立运行回执全部通过且最终产物哈希匹配后生成。包内文件的完整性清单为 `SHA256SUMS.json`；这份验证记录不代替实体手机上的使用反馈。

Git 修复通过独立分支提交，不自动合并主分支。合并后可从原仓库正常更新；临时手动升级须覆盖原扩展目录内容（可能叫 `-SSSR`），保留 `.git`，不要并排安装第二份商店。主题脚本在酒馆助手单独替换，原四表无需重装。
