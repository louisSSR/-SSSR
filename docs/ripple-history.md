# 连锁反应历史

账本继续使用 v1 格式，新增可选字段 `rippleHistory`。没有此字段的旧账本和旧备份仍可读取、导入；完整备份会携带新历史。

`ripples` 保存每条连锁反应的当前状态。追踪内容、已结算作用、状态等业务字段实际变化时，程序先把完整旧记录追加到 `rippleHistory`，再更新当前记录。相同内容的重复提交不会刷新时间、增加账本版本或追加相同历史。结束的连锁反应保留当前记录并标记 `resolved`，不能直接删除。

历史包含原记录 ID、世界、来源、已结算作用、后续追踪、状态和 UTC 时间。已经保存的历史不能删除、改写或重排；一次事务可以连续更新多条记录或同一记录多次，每个被替换的版本都保留。连锁反应和它的历史本身不产生点数交易。

**旧版曾按 ID 覆盖的更早内容无法从现有账本还原。** 更新后从当前仍保留的版本开始连续归档，不补造过去。若用户另有旧导出文件，可保留为独立备份参照，不能假称本次升级恢复了不存在的数据。

AI 摘要使用有限的当前状态；缩减摘要不删除历史。归档达到当前每类十万条实现上限时，更新会被拒绝并保留全部已有记录，不会偷偷清理旧版本。新机制不改变余额、价格、交易或资产规则。
